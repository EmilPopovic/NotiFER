Moving to a new machine
  1. Here: download a bundle above. Copy ENCRYPTION_KEY and TIMEZONE out of .env separately.
  2. New machine: run deploy.sh, then fill .env — same ENCRYPTION_KEY and TIMEZONE, fresh SMTP credentials, and the new API_URL if the hostname changed.
  3. Set WORKER=false and DATA_IMPORT=true, then make initdb.
  4. Import the bundle — validate first, then apply.
  5. Run make verifydb. It decrypts every stored token and names any that fail, which is how an ENCRYPTION_KEY mismatch shows up immediately instead of as a worker crash an hour later.
  6. Set WORKER=true and DATA_IMPORT=false, restart, move DNS, shut the old machine down.
  7. Delete the bundle from both machines.

SMTP credentials, DASHBOARD_PASSWORD_HASH and NOTIFER_API_TOKEN_HASH are deliberately not in the bundle. Set them by hand.
